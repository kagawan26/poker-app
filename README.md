# POKER HOUSE ♠

無料チップでテキサスホールデムを練習できる、スマートフォン対応のブラウザアプリです。

## 遊び方

`index.html` をブラウザで開いてください。インストールやアカウント登録は不要です。

- 1対1のCPU対戦
- 52枚のカードからランダム配布
- フロップ・ターン・リバー
- フォールド・チェック/コール・レイズ
- 7枚から最善の5枚を選ぶ役判定
- 1,000チップでスタート。所持チップが足りなくなれば自動リセット

## 制限事項

これはローカルの練習用プロトタイプです。実際のオンライン対戦、ユーザー認証、ゲーム履歴保存、トーナメント、アプリストア配布、現金・換金・賞品との交換には対応していません。ベッティングは簡略化されており、サイドポット、厳密なポジション交代、複数ラウンドのリレイズ、競技用の全ルールには未対応です。

## 公開方法

GitHub Pages を有効化して、ブランチ `main` のルートを公開すれば HTTPS でアクセスできます（このリポジトリの Pages 設定は別途必要です）。
